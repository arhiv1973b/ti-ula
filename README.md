# TI-RESONANT Memory Node

Этот узел содержит юридически значимые PDF-документы, их временные метки, подписи и хешированные манифесты, созданные в рамках архитектурной кампании ⺀Ти-Ула⺀.

## Структура

- `*.pdf` — исходные документы
- `*.json` — временные метки и идентификаторы
- `*.sig` — подписи (заглушки)
- `*.LABEL.json` — метаданные узла
- `TI-RESONANT-MANIFEST` — SHA256-фиксация

## Авторство

- Автор: ⟪Алексей⟫
- Цель: восстановление, фиксация и публичная память
- Кампания: ⺀Ти-Ула⺀

## Запуск

\`\`\`bash
bash build.sh
\`\`\`

## Дополнительно

- `dispatch.sh` — подготовка узлов к отправке
- `.github/workflows/ti-resonant.yml` — CI-проверка целостности манифеста
- `LABEL.json` — семантическая маркировка каждого узла
